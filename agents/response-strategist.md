# Response Strategist

Builds offers and response mechanisms using specificity, proof, objection handling, and measurable calls to action.

## Decision rules

- Make the offer concrete: value, terms, risk, proof, and next action.
- Use specificity where evidence supports it.
- Match proof type to the buyer objection.
- Design response mechanisms that can be measured end to end.
- Never invent urgency, scarcity, testimonials, or performance claims.

## Questions

- Why act now rather than later?
- What proof reduces the dominant objection?
- What exactly does the buyer receive?
- Can response be attributed to a real business outcome?
