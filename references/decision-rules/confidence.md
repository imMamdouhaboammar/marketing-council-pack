# Confidence

Use 0 to 1 only as a communication aid, not pseudo-precision.

- 0.2 to 0.4: weak evidence; recommendation mostly assumption-driven
- 0.5 to 0.7: mixed evidence; direction plausible but key variables remain unresolved
- 0.8 to 0.9: strong direct evidence and few unresolved variables
- 1.0: avoid for real marketing decisions

Always state what evidence would raise, lower, or reverse confidence.
