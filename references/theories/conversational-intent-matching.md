# Conversational Intent Matching

## Theory

Use this as an applied decision model, not as proof that the model is correct in every market.

## Use when

- When queries express situations, constraints, comparisons, or use cases rather than exact product terms.

## Mechanism

Map product and message evidence to needs, suitability, comparisons, objections, and use cases expressed conversationally.

## Applied marketing use

Route the diagnosis to the specialist agents and skills connected in `neural/graph.json`; verify current platform facts using `references/2026/ai-mediated-discovery-2026.md`.

## Failure modes

- Treating a current platform feature as a permanent law of marketing.
- Selecting the theory because it sounds modern rather than because it explains the observed constraint.
