# Council Debate Workflow

Use only when credible specialist views disagree.

For each conflict:
1. State the issue precisely.
2. Present position A and its assumptions.
3. Present position B and its assumptions.
4. Identify the variables that decide between them.
5. Use evidence, economics, constraints, and time horizon to choose.
6. Give confidence from 0 to 1.
7. State the evidence that would reverse the choice.

Do not synthesize incompatible positions into a vague compromise.
