# Full Strategy Workflow

1. Frame the business decision, outcome, horizon, and constraints.
2. Build an evidence map and freshness plan.
3. Run market diagnosis.
4. Select the relevant council roles.
5. Resolve audience, category frame, positioning, offer, channel, and economics in that order when they depend on one another.
6. Run council debate where recommendations conflict.
7. Produce one primary strategic choice and explicit exclusions.
8. Translate the choice into prioritized tactics and experiments.
9. Run pre-mortem and post-strategy red team.
10. Define measurement, thresholds, decision dates, and learning capture.
